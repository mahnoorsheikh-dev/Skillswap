# SkillSwap

A skill exchange platform where people connect to teach what they know and learn what they don't.

## Tech Stack
- React, Tailwind CSS
- Node.js, Express
- MongoDB, Mongoose
- Socket.io (real-time chat)
- Cloudinary (image uploads)
- JWT Authentication

## Live Demo
- Frontend: https://skillswap-client-swart.vercel.app
- Backend: https://skillswap-six-taupe.vercel.app

## Known Limitations
- Real-time chat does not work on Vercel due to WebSocket limitations. Works fully in local development.

## Features
- Signup / Login with JWT
- Profile with avatar upload
- Find and connect with other users
- Real-time chat (local)
